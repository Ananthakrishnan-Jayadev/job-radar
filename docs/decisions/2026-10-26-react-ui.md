# 2026-10-26: React + TypeScript UI, one server

Replaces "Jinja2 templates + htmx" from the original plan (PROJECT.md §4).

- **The user wants a React UI, run from one terminal.** The UI is React +
  TypeScript, built with Vite into `jobradar/web/static/`. FastAPI serves the
  JSON API under `/api` and the built files for every other path, so
  `jobradar serve` is the only command. `jobradar serve --dev` also runs
  `vite build --watch` as a child process for UI work, still one terminal.
- **TypeScript**, so the UI's types mirror the API and mistakes between the
  two show up at build time.
- **Minimal UI dependencies:** react, react-dom, react-router-dom; Vite and
  TypeScript for building. Plain CSS, React state.
  *Changed 2026-10-27:* Tailwind, Motion, Lucide, NumberFlow and a
  self-hosted font were added at the user's request; see
  `2026-10-27-ui-themes-and-motion.md`.
- **Installs:** the human runs every install and build after a phase
  (`pip` into `.venv`, `npm install` / `npm run build` in `frontend/`). The
  agent writes code and pytest tests for the API only; it does not install,
  build or run the UI. Node 24 is already on the machine.
- `jinja2` and `python-multipart` are dropped from the Python dependencies.
- `frontend/node_modules/` and the built `jobradar/web/static/` are
  git-ignored; build after cloning.
