# 2026-10-27: HiBob connector

Xanadu's careers site (`xanadu.careers.hibob.com`) is a script app with no
jobs in the page. Reading the app's code showed it loads every job, with the
full description, from one public request:
`GET https://{company}.careers.hibob.com/api/job-ad`.

- **Needs `Referer: https://{company}.careers.hibob.com/jobs`;** without it
  the API answers 401. The first scan failed this way (the probe had sent a
  Referer, the connector hadn't); fixed the same day.
- **Undocumented,** like Workday and BambooHR: it can change without notice.
- **Job page:** `{site}/jobs/{id}`.
- **Pasted links** are recognized, and `find-boards` tries HiBob by name.

Boards: Xanadu (86 jobs, 72 in Canada) and Helcim (9). Details in
`docs/03-data-sources.md`.
